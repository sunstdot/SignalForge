Andrej Karpathy: 未来一年 AI Coding 的演进方向，以及为何当前工具仍有根本性局限

💬 karpathy 对 AI coding 工具的批判很有深度，值得结合我们自己的产品思考
⚡ 速读摘要▼
核心内容：Karpathy 认为当前 AI coding 工具在上下文管理和长任务规划上存在根本性缺陷，预测未来 12 个月将出现「代码理解型」Agent 而非「代码生成型」工具。

关键信息：
- 当前工具本质是「自动补全++」，缺乏对整个代码库的理解
- 真正的突破在于 persistent memory + codebase graph 结合
- 未来 Agent 会主动维护对项目的「心智模型」
💼 商业机会▼
开发面向中小团队的「代码库理解层」工具，作为现有 AI coding 助手的中间件，提供持久化的项目语义图谱。目标用户：10-50 人工程团队，痛点是 AI 工具在大型 monorepo 中的失效问题。
🔬 研发机会▼
研究方向：基于增量更新的代码库语义图（Code Knowledge Graph），结合 AST 解析与 LLM embedding，实现跨文件的上下文压缩。技术路径：Tree-sitter + 向量索引 + 增量 diff 更新机制。
