### Investigating Autonomous Agent Contributions in the Wild: Activity Patterns and Code Change over Time

本研究构建了一个包含约11万个开源pull requests的新数据集，系统性地比较了五种主流AI编码代理（OpenAI Codex、Claude Code、GitHub Copilot、Google Jules和Devin）在实际软件开发中的贡献模式。研究不仅分析了这些AI代理的合并频率、编辑文件类型和开发者交互等即时指标，还特别关注了代码的长期可维护性，发现AI生成的代码虽然在开源项目中使用日益增加，但相比人类编写的代码呈现出更高的代码流失率（churn rate）。

#

**核心见解：**
- **首个大规模实证研究**：这是首次针对自主AI编码代理在真实开源项目中的活动模式进行的大规模系统性研究，数据集涵盖数百万行源代码及完整的开发协作信息
- **AI代码质量的长期视角**：研究突破了传统关注代码生成准确性的局限，强调代码的长期存活率和维护成本，发现AI生成代码的churn rate更高，暗示潜在的可维护性问题
- **多维度对比分析**：通过比较五种主流AI编码工具在合并率、文件类型偏好、开发者交互（评论/审查）等多个维度的差异，揭示了不同AI工具的使用特征和局限性
- **软件工程全流程视角**：明确指出代码编写和审查只是软件工程的一小部分，AI代理对整个软件生命周期（特别是维护阶段）的影响需要持续关注和评估

### GPT-NL Public Corpus: A Permissively Licensed, Dutch-First Dataset for LLM Pre-training

GPT-NL Public Corpus 是目前最大的荷兰语开放许可语料库，专为大语言模型预训练设计。该语料库包含 36B 个独特的荷兰语 token，以及超过 487B 个其他语言（英语、代码、德语/丹麦语）的 token，所有数据均来自具有宽松许可的数据集，并以 CC-BY 许可证重新发布在 Hugging Face Hub 上。

**核心见解：**
- **荷兰语优先的大规模资源**：包含 21 个荷兰语专属数据集，提供 36B 个在其他 LLM 预训练语料库中不存在的荷兰语 token，填补了荷兰语 NLP 资源的空白
- **多语言支持与合规性**：除荷兰语外，还包含约 207B 英语、232B 代码和 48B 德语/丹麦语 token，所有数据经过严格的许可证合规性审查
- **合作与合成数据创新**：新创建的荷兰语数据集主要通过与组织机构合作收集或通过合成方法增强，确保数据的合法性、实用性和无害性
- **完全开放可商用**：所有数据采用宽松的 CC-BY 许可证发布，支持商业化语言模型的开发，降低了企业和研究机构的使用门槛

### PsychAgent: An Experience-Driven Lifelong Learning Agent for Self-Evolving Psychological Counselor

本文提出了PsychAgent，一个用于心理咨询的经验驱动型终身学习智能体。该系统通过三个核心引擎（记忆增强规划引擎、技能进化引擎和强化内化引擎）实现持续自我进化，模仿人类心理咨询师通过临床实践不断提升专业能力的过程。实验表明，PsychAgent在多维度评估中优于GPT-4和Gemini等通用大模型以及领域专用基线模型。

#

**核心见解：**
- **核心创新**：突破了传统AI心理咨询依赖静态数据集监督微调的局限，首次引入终身学习机制，使模型能像人类专家一样从实践经验中持续学习和进化
- **三引擎架构**：记忆增强规划引擎保证多会话治疗连续性，技能进化引擎从历史咨询轨迹中提取新技能，强化内化引擎通过拒绝微调将技能整合到模型中
- **纵向交互能力**：专门针对心理咨询的多会话长期交互场景设计，通过持久化记忆和战略规划确保治疗的一致性和连贯性
- **性能优势**：在所有评估维度上超越GPT-4、Gemini-3等强大通用模型，证明了终身学习范式在提升多会话咨询质量和一致性方面的有效性
