### GPT-NL Public Corpus: A Permissively Licensed, Dutch-First Dataset for LLM Pre-training

GPT-NL Public Corpus 是目前最大的荷兰语开放许可语料库，专为大语言模型预训练设计。该语料库包含 36B 个独特的荷兰语 token，以及超过 487B 个其他语言（英语、代码、德语/丹麦语）的 token，所有数据均来自具有宽松许可的数据集，并以 CC-BY 许可证重新发布在 Hugging Face Hub 上。

**核心见解：**
- **荷兰语优先的大规模资源**：包含 21 个荷兰语专属数据集，提供 36B 个在其他 LLM 预训练语料库中不存在的荷兰语 token，填补了荷兰语 NLP 资源的空白
- **多语言支持与合规性**：除荷兰语外，还包含约 207B 英语、232B 代码和 48B 德语/丹麦语 token，所有数据经过严格的许可证合规性审查
- **合作与合成数据创新**：新创建的荷兰语数据集主要通过与组织机构合作收集或通过合成方法增强，确保数据的合法性、实用性和无害性
